# Очистка Claude на macOS

`clean-claude.sh` очищает известные локальные данные **Claude Code и Claude Desktop**
для текущего пользователя. Работает со штатным `/bin/bash` 3.2 на Apple Silicon
и Intel, без Homebrew, Python и дополнительных утилит.

## Запуск

Закройте Claude Desktop, терминальные/фоновые сессии Claude Code и IDE с его
расширением. Затем запустите:

```bash
bash clean-claude.sh
```

Скрипт сначала выведет список файлов, каталогов и записей Keychain на удаление,
затем попросит ввести `DELETE`. До этого ввода ничего не удаляется и Keychain
не открывается. Другой ответ, пустой ввод или `Ctrl+D` отменяют очистку.
Подтверждение обязательно, ввод через pipe не принимается.

Для просмотра списка без запроса подтверждения:

```bash
bash clean-claude.sh --dry-run
```

Удаление безвозвратное:
история, автоматическая память, локальные учётные данные и персональные настройки
из плана будут потеряны. Это включает `~/.claude.json` с личными настройками MCP,
`~/.claude/settings.json` и `claude_desktop_config.json`. Впоследствии понадобится
войти в аккаунт и настроить приложения заново. Резервные копии удаляемых данных
скрипт не создаёт.

Дополнительные варианты:

```bash
bash clean-claude.sh --apply             # как обычный запуск, с подтверждением
bash clean-claude.sh --scope code        # список и подтверждение только для Code
bash clean-claude.sh --scope desktop     # список и подтверждение только для Desktop
bash clean-claude.sh --keep-keychain     # сохранить авторизацию в Keychain
bash clean-claude.sh --help
```

Опции можно сочетать. Обход подтверждения через `--yes` отключён; совместный
запуск `--apply --dry-run` отклоняется. Не используйте `sudo`.

## Какие данные входят в очистку

| Место | Данные |
| --- | --- |
| Известные подпапки `~/.claude` | Диалоги, память проектов и агентов, журналы, планы, задания, статистика, кэши, снимки файлов и окружения, резервные копии конфигурации |
| Известные файлы `~/.claude` и `~/.claude.json` | Настройки, идентификаторы, история ввода, файловая авторизация и состояние |
| `~/Library/Caches/claude-cli-nodejs`, `~/.cache/claude`, `~/.local/state/claude` | Кэши и состояние Code |
| `/private/tmp/claude-<uid>` и `claude-<uid>` в пользовательской временной папке macOS | Временные данные, если внутри нет признаков исходников |
| Известные элементы `~/Library/Application Support/Claude` | Cookies, веб-хранилища, кэши Electron, настройки и сессии вкладки Code |
| Точные каталоги Claude в `~/Library/{Caches,Logs,HTTPStorages,WebKit,Saved Application State}` | Логи, HTTP-данные, кэши и состояние окна |
| `~/Library/Preferences/com.anthropic.claudefordesktop.plist` | Настройки Desktop |
| Пользовательская связка ключей `login` | Только перечисленные ниже точные пары service/account |

Полный список путей задан в функциях `cc_code_manifest` и `cc_desktop_manifest`.
Имена Desktop проверены по локальной установленной версии 1.12603.1; устройство
хранилищ может меняться. В новых версиях незнакомые пути сохраняются.

Keychain обрабатывается через `security` без чтения или вывода паролей:

- `Claude Code-credentials` / имя текущего пользователя;
- `Claude Code` / имя текущего пользователя;
- `Claude Code-device-keys` / имя текущего пользователя;
- `Claude Safe Storage` / `Claude Key`.

При просмотре Keychain вообще не открывается. При удалении macOS может запросить
разрешение на изменение записи. Заблокированная связка и ошибки доступа выводятся
как пропуски. Иные связки ключей, нестандартные имена записей, профили и записи
других программ не перебираются и не удаляются.

## Сохранность исходников

Скрипт не сканирует проекты и весь диск по маске `*claude*`. Домашняя папка
определяется через учётную запись macOS, а не через подменяемую переменную `HOME`.
Удаление ограничено явным списком. Каждый путь проверяется повторно непосредственно
перед удалением, включая тип, владельца и идентичность объекта.

Сохраняются с отметкой `СОХРАНИТЬ`:

- инструкции `CLAUDE.md`, skills, hooks, плагины, пользовательские команды,
  неизвестные файлы и папки непосредственно внутри каталогов данных;
- каталог из списка удаления целиком, если в нём найдены репозиторий, worktree,
  исполняемые файлы, распространённые расширения исходников, жёсткие или символические
  ссылки, чужие файлы, особые файлы либо возникла ошибка чтения;
- пути с символическими ссылками в любом компоненте;
- `git-worktrees.json`, окружения и результаты Cowork: `local-agent-mode-sessions`,
  `claude-code-vm`, `vm_bundles`; внутри них могут находиться единственные копии работы;
- нестандартные хранилища из `CLAUDE_CONFIG_DIR`, `CLAUDE_CODE_TMPDIR`, `XDG_CACHE_HOME`.

Штатные `snapshot-*.sh` / `snapshot-*.zsh` в `shell-snapshots` — исключение
из проверки расширений: это снимки оболочки Claude, они входят в очистку.
Исходные `.zshrc`, `.bashrc` и другие файлы
оболочки сохраняются. Снимки в `file-history` также относятся к удаляемой истории,
включая снимки `*@v<номер>` с правом выполнения; исходные файлы проектов
остаются на месте.

Каталоги удаляются через `find -P -xdev -depth -delete`: без перехода по ссылкам
и на вложенные файловые системы. Непустые или смонтированные каталоги останутся
с сообщением об ошибке. Корневые `~/.claude` и `Application Support/Claude`
удаляются через `rmdir`, только если после очистки в них ничего не осталось.
Во время выполнения не запускайте Claude и не перемещайте
его данные: проверки Bash не обеспечивают атомарную защиту от одновременной
подмены файлов другими процессами.

Расположение и имя файла не позволяют безошибочно установить его происхождение.
Если вы вручную складывали ценные данные в перечисленные служебные хранилища,
перенесите их до очистки. Предварительный просмотр показывает удаляемые каталоги
целиком, а не каждый вложенный файл.

## Ограничения полного сброса

Условие «Claude не сможет понять, что уже использовался» нельзя гарантировать
локальным скриптом при обязательном сохранении исходников и данных других программ.
Сохраняемые инструкции, плагины, worktree и окружения Cowork могут содержать историю.
В конце скрипт явно сообщает о неполной очистке, если есть такие остатки.

Скрипт также сохраняет приложения и CLI, расширения IDE/браузеров, историю браузеров
и терминала, общие базы IDE, Git, системные журналы macOS, TCC-разрешения, управляемые
настройки организации, Time Machine/APFS-снимки и экспортированные пользователем
файлы. Пользовательские API-ключи в переменных окружения и shell-профилях сохраняются.
Он не отзывает токены на сервере и не удаляет облачный аккаунт или его историю.
После повторного входа часть данных может синхронизироваться снова.

Anthropic описывает [локальные данные Code](https://code.claude.com/docs/en/claude-directory),
[хранение авторизации](https://code.claude.com/docs/en/authentication),
[worktree в Desktop](https://code.claude.com/docs/en/desktop#work-in-parallel-with-sessions)
и [серверное хранение данных](https://code.claude.com/docs/en/data-usage#data-retention).

Коды завершения: `0` — выбранный план/очистка завершены; `1` — обнаружены сохранённые
остатки или ошибки; `2` — ошибка аргументов, платформы или подтверждения;
`3` — работающий Claude либо невозможность проверить процессы. Код `1` при просмотре
означает наличие строк `СОХРАНИТЬ`, а не удаление каких-либо файлов.

## Проверка

Интеграционные тесты требуют macOS и Python 3. Они запускают настоящую логику
удаления только во временном дереве, заменяя определение домашней/временной папки,
проверку процессов и вызовы Keychain. `HOME` не меняется.
Запрос подтверждения проверяется через псевдотерминал: список виден до удаления,
очистка начинается после `DELETE`, а отказ и конец ввода сохраняют данные.

```bash
/bin/bash -n clean-claude.sh
python3 -m unittest discover -s tests -v
```
